## 2. 파일 형식

### subjects.json
- 기본 필드: `name`(고시 표기), `area`(교과), `type`(공통/일반선택/진로선택/융합선택), `aliases`(표기 변형).
- `special`(선택 필드)
  - "공통과목 대체이수(151과목 미포함)": 기본수학1·2, 기본영어1·2
  - "과학계열 특목고 전공 관련 과목(총론 표6)": 수학·과학·정보만 넣음
- 범위: <표5> 151과목 전부(모든 교과) + 대체이수 4 + <표6> 수학·과학·정보 15 = **170개**.
- <표6>의 체육·예술·외국어 계열 과목과 전문교과는 넣지 않았다.
- `area` 값: 국어, 수학, 영어, 사회(역사/도덕 포함: 한국사1·2 포함), 과학, 기술·가정, 정보, 제2외국어, 한문, 체육, 예술, 교양.

### universities/<key>.json
- 담은 대학과 모집단위(자연·공학·의약만): 서울대 39, 연세대 33, 고려대 32, 경희대 37, 중앙대 24, 부산대 52, 한양대 1.
- `core` / `recommended`는 RULE 배열이다. **한 배열 안의 RULE은 모두 충족해야 한다(AND).**
  - `{"all":[A,B]}`: A와 B 모두 이수.
  - `{"choose":N,"of":[...]}`: 목록 중 **N과목 이상** 이수.
  - `all`과 `choose`에 같은 과목이 함께 나올 수 있다. 예: 서울대 의예과는 "세포와 물질대사·생물의 유전을 포함하여 진로선택 3과목 이상"이라 `all`과 `choose 3`을 함께 쓴다. 대조할 때 한 과목이 두 RULE을 동시에 채울 수 있다.
- `raw`: 원문 문구를 그대로 옮겼다(어디가 xlsx 칸 내용, 줄바꿈만 공백으로).
- `note`: 우리가 해석한 내용을 적는다. "해석 확인 필요"는 원문만으로 규칙을 정할 수 없었다는 뜻이다.
- `source_ref`: 1장 표의 키. 행마다 출처를 단다.
- `field`: 공학/자연/의약. 우리가 단과대학·학문 분야로 분류했다(원문에는 없는 값).

## 3. 대학별 해석 원칙

- **핵심(core)과 권장(recommended)**
  - 원문이 둘을 구분하는 경우에만 `core`를 쓴다.
    - 경희대: 어디가 xlsx 열 구분 그대로.
    - 부산대: 어디가 xlsx '핵심과목' 열에 기재되어 `core`에 넣었고, 대학 원문은 대조하지 못함.
    - 한양대: 어디가 xlsx '핵심과목' 열에 기재되어 `core`에 넣었다.
  - 서울대(2028부터 구분 폐지), 연세대·고려대·중앙대(권장만 제시)는 `recommended`에만 넣었다.
- **서울대**
  - 유형②(자연·의약) 행만 넣었다.
  - "과학"은 '과학 교과 진로선택 과목 중 3과목 이상' 비고에 따라 진로선택 8과목 중 `choose 3`으로 옮겼다.
  - 핵심과목 열의 "물리학" 등은 모집단위가 우선 권장하는 일반선택 과목으로 해석했다.
  - 식품영양학과·의류학과는 유형①(제2외국어/한문) 행도 있어 "해석 확인 필요"로 표시했다.
- **고려대**: 비고 "과학 교과 권장 과목 중 2과목 이상"이 있으면 과학 과목을 `choose 2`로, 수학 과목은 `all`로 나눴다.
- **중앙대**: 비고 "*A, B, C, D: N과목 이상"이 있으면 해당 과목을 `all`에서 빼고 `choose N`으로 옮겼다. 중앙대 PDF 표와 같다.
- **부산대**
  - "제시 과목 관련 일반선택·진로선택 중 N과목 이상"은 같은 표에 적힌 정의로 전개했다.
    - 물리학 관련: 물리학, 역학과 에너지, 전자기와 양자
    - 화학 관련: 화학, 물질과 에너지, 화학 반응의 세계
    - 생명과학 관련: 생명과학, 세포와 물질대사, 생물의 유전
    - 지구과학 관련: 지구과학, 지구시스템과학, 행성우주과학
  - 경제통상대학·경영대학 행(인문)은 뺐다.
- **연세대**
  - 모든 자연·의치약 모집단위: `all [기하, 미적분Ⅱ]` + 과학 진로선택 `choose 3`.
  - 과학 일반선택이 "자율선택"인 14개 모집단위는 이수 개수가 명시되지 않아 규칙을 만들지 않았고 "해석 확인 필요"로 표시했다.
  - 인문·통합계열은 원문이 "전공연계과목 미제시"라 넣지 않았다.
- **한양대**: 원문이 "자연 전 모집단위" 1행뿐이라 모집단위 1개로 넣었다.

## 4. 정규화 규칙 (시간표·원문 과목명 → subjects.json `name`)

1. **공백 무시 비교**: 양쪽 공백을 모두 지우고 비교한다(예: "화학반응의 세계" → 화학 반응의 세계). `aliases`에는 공백을 모두 뺀 형태만 넣었으므로, 부분 공백 변형은 이 규칙으로 처리한다.
2. **로마 숫자**: Ⅰ(U+2160)/Ⅱ(U+2161)를 정본으로 하고, I/II, 1/2, 앞 공백 변형("미적분 Ⅱ")을 aliases에 넣었다.
3. **가운뎃점**: "기술·가정"의 ·(U+00B7)를 정본으로 하고, ㆍ(U+318D)·・(U+30FB)·생략형을 aliases에 넣었다.
4. **NEIS 시간표 블록 꼬리표 제거**: `ITRT_CNTNT` 끝의 `[A-Z]\d+`(예: "주제 탐구 독서D1", "윤리와 사상A3")와 `_[A-Z]\d+`(예: "자율활동_G1")를 지운 뒤 대조한다. 2026-10-10 가락고 표본 호출에서 관찰했다.
5. **실제로 관찰된 오타·변형**(aliases에 넣음, 모두 어디가 xlsx에서 관찰)

   | 관찰된 표기 | 정본 |
   |---|---|
   | 생물과 유전 (경희대 생명계열 행) | 생물의 유전 |
   | 주제탐구 독서 | 주제 탐구 독서 |
   | 동아시아 역사기행 | 동아시아 역사 기행 |
   | 도시의 미래탐구 | 도시의 미래 탐구 |
   | 영어독해와 작문 | 영어 독해와 작문 |
   | 사화와 문화 | 사회와 문화 |
   | 국제관계의 이해 | 국제 관계의 이해 |
   | 스포츠과학 | 스포츠 과학 |
   | 기술가정 | 기술·가정 |

6. **2015 개정 과목명은 별칭으로 넣지 않는다.** 물리학Ⅰ, 화학Ⅱ, 미적분, 수학Ⅰ, 언어와 매체 등은 다른 교육과정의 과목이다. 2026년 고3 시간표에 나온다. 학교 데이터 수집 때 2015 개정 교육과정을 배우는 학년(입학연도 2024년 이전)의 시간표는 "운영 확인"에서 뺀다. 기하·확률과 통계·영어Ⅰ처럼 두 교육과정에서 이름이 같은 과목이 2028 지원자에게 잘못 "운영 확인"으로 보이는 것을 막기 위해서다.
7. **교육감 승인(고시 외) 과목**은 사전에 없다. 대조 결과는 "사전에 없는 과목"으로 표시하고 매칭하지 않는다.
8. 모집단위명 오타: 부산대 "검퓨터공학전공"을 "컴퓨터공학전공"으로 고치고 note에 기록했다.
9. 제외한 행: 부산대 "공과대학 | 수학교육과". 사범대학 수학교육과와 중복된 것으로 보이는 xlsx 오류다.

- 성균관대·서강대 등은 공개 자료를 확인하지 못해 넣지 않았다.
