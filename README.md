# 권장과목 맞춰보기 (hs-subject-match)

가고 싶은 학과의 **2028 대입 권장과목**을 보고, **우리 학교 시간표에 실제로 나온 과목**과 내가 들었거나 들을 과목을 맞춰 보는 웹 도구입니다.

👉 **https://Raonkim.github.io/hs-subject-match/**

## 왜 만들었나

- 2028 대입부터 대학들이 모집단위별 **전공 연계 권장과목**(2022 개정 교육과정 과목명)을 내놓았습니다. 그런데 기준이 대학마다 다릅니다. 같은 자연계열이라도 기하·미적분Ⅱ를 둘 다 권하는 곳과 하나만 권하는 곳이 있습니다.
- 학생이 실제로 묻는 건 "**그 과목을 우리 학교에서 들을 수 있나?**"입니다. 권장과목 목록은 대학 PDF와 대교협 엑셀에 흩어져 있고, 학교별 개설 과목과 맞춰 주는 공개 서비스는 찾지 못했습니다(2026-10 기준).
- 형식이 제각각인 공급자 데이터를 하나의 규칙 형식으로 정리하는 것이 이 프로젝트의 핵심입니다. 대학별 문구("과학 교과 진로선택 중 3과목 이상" 등)를 `{"choose": 3, "of": [...]}` 같은 규칙으로 옮기고, 원문 문구를 그대로 함께 보여 줍니다.

### 데이터 한계 (화면에도 표시)

- **'운영 확인'은 표본 기간 시간표에 나왔다는 뜻입니다.** 선택과목은 학급 시간표에 일부만 보일 수 있어서 '확인 안 됨'이 '개설 안 됨'은 아닙니다.
- **아직 오지 않은 학기(특히 3학년)의 과목은 시간표에 없습니다.** 학교 교육과정 편제표(학교알리미)로 확인해야 합니다.
- 해석이 애매한 모집단위 17곳(연세대 14, 서울대 2, 부산대 1)은 애매한 부분만 규칙에서 빼고 나머지로 판정합니다. 화면에서는 요약 바로 아래에 "원문을 꼭 확인하라"는 경고를 띄웁니다.
- 서울대·고려대·경희대·중앙대·부산대·한양대 규칙은 어디가 자료 기준입니다. 2026-10-14 독립 검수에서 어디가 원본과 185개 모집단위를 전부 기계로 대조했고, 실질 불일치는 없었습니다.
- 연세대(33개)는 대학 공식 PDF(2026.4)가 출처이며, 2026-10-14에 PDF 원문 표와 33개 모집단위 전부를 한 줄씩 대조해 일치를 확인했습니다.
- 2015 개정 교육과정을 배우는 학년(2026학년도 고3)의 시간표는 '운영 확인'에서 뺍니다. 기하·영어Ⅰ처럼 두 교육과정에서 이름이 같은 과목이 잘못 확인되는 것을 막기 위해서입니다.
- **권장과목은 지원 자격이 아닙니다.** 최종 판단은 대학 모집요강과 입학처 공지로 하세요.

## 보안·개인정보

- 위협 모델: 학생이 고른 학교·학과·이수 과목이 밖으로 새는 것, NEIS 인증키가 공개 저장소에 노출되는 것.
- 서버가 없습니다. 고른 값은 브라우저 안에서만 쓰이고 저장·전송하지 않습니다(분석 스크립트·쿠키 없음, CSP `connect-src 'self'`).
- NEIS 키는 GitHub Actions Secret(`NEIS_API_KEY`)으로만 쓰고, 수집 스크립트는 오류 메시지와 결과 파일에 요청 URL을 남기지 않습니다(NEIS 약관 제7조).

## 개발

```bash
npm test                     # 규칙·정규화 테스트 (의존성 없음)
npm run build                # data/ 검증 후 docs/data/ 로 복사
NEIS_API_KEY=... node tools/build_schools.mjs --ay 2026 --region B10 --limit 20
python -m http.server 8000 --directory docs
```
